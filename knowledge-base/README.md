## 用途

1. **Dify 知识库**：在 Dify 平台创建知识库后，把本目录 6 份 Markdown 上传，
   供「医师咨询助手（CHAT-1）」「AI 智能助手（CHAT-2）」「健康资讯生成（WF-4）」等应用检索引用；
2. **前端内容**：`js/seed.js` 中的糖尿病类型知识、生活注意事项与科普文章，
   均以本目录文档为来源进行结构化提炼；
3. **内容边界**：本知识库为健康科普与管理建议，不包含具体用药剂量，
   页面统一展示医疗免责声明。
